### **User Manual: Concrete Mixture Calculator**
แอปพลิเคชันนี้ออกแบบมาเพื่อช่วยวิศวกรและผู้รับเหมาคำนวณปริมาณวัสดุผสมคอนกรีต (ปูน, ทราย, หิน, น้ำ) จากขนาดโครงสร้างที่ต้องการเทจริง

**ขั้นตอนการใช้งาน:**
1. **กรอกขนาดโครงสร้าง (Dimensions):** ผ่านแถบเมนูด้านซ้าย (Sidebar)
   * **Width:** ความกว้างของพื้นที่ (เมตร)
   * **Length:** ความยาวของพื้นที่ (เมตร)
   * **Thickness/Height:** ความหนาของพื้น หรือความสูงของเสา/คาน (เมตร)
2. **ระบุค่าเผื่อเหลือเผื่อขาด (% Waste):** ปรับเลื่อนแถบ **Slider** เพื่อกำหนดเปอร์เซ็นต์ที่ต้องการเผื่อ เช่น 5% หรือ 10% เพื่อป้องกันวัสดุไม่พอเนื่องจากการหกหล่นหรือพื้นผิวที่ไม่เรียบ
3. **เลือกสัดส่วนผสม (Mixing Ratio):** เลือกจากรายการ **Dropdown** ตามประเภทงาน:
   * **[1:1.5:3]:** สำหรับงานโครงสร้างที่ต้องการความแข็งแรงสูง (คาน, เสา)
   * **[1:2:4]:** สำหรับงานทั่วไป (พื้นบ้าน, ถนน)
   * **[1:3:5]:** สำหรับงานโครงสร้างไม่รับแรงมาก (ลีนคอนกรีต, ปรับระดับพื้น)
4. **การอ่านผลลัพธ์:** แอปจะแสดงผลลัพธ์แบบ Real-time บนหน้าจอหลัก ทั้งในรูปแบบตัวเลขสรุป (Metrics) และกราฟวงกลม (Pie Chart) แสดงจำนวนถุงปูน (ปัดเศษขึ้น), ปริมาตรทรายและหิน (ลบ.ม.), และปริมาณน้ำโดยประมาณ

### **Explanation of Code**
โค้ดชุดนี้แบ่งการทำงานออกเป็นส่วนๆ อย่างเป็นระบบ ดังนี้

**ส่วนรับข้อมูลและป้องกันข้อผิดพลาด (Input Validation)**
ใช้ฟังก์ชันจากไลบรารี **Streamlit** ได้แก่ `st.sidebar.number_input` และ `st.sidebar.slider` ซึ่งทำหน้าที่ควบคุมให้ผู้ใช้กรอกได้เฉพาะตัวเลขที่อยู่ในช่วงที่กำหนดเท่านั้น ช่วยป้องกันปัญหาโปรแกรมค้าง (Crash) จากการกรอกข้อมูลผิดประเภท

**ส่วนตรรกะการคำนวณ (Engineering Logic)**
* **Net Volume:** คำนวณปริมาตรสุทธิจากรูปทรงสี่เหลี่ยม ($V = W \times L \times H$)
* **Total Volume:** นำปริมาตรสุทธิมาบวกค่า Waste ตามที่ผู้ใช้กำหนด
* **การคูณด้วย 1.54:** นี่คือจุดสำคัญทางวิศวกรรม เพราะคอนกรีตเมื่อผสมน้ำจะมีการยุบตัว เราจึงต้องคูณด้วยค่า **Shrinkage Factor (1.54)** เพื่อหาปริมาตรวัสดุแห้งที่ต้องสั่งจริงก่อนนำไปผสมน้ำ
* **Sum Ratio:** นำสัดส่วนที่เลือกมาหาผลรวม (เช่น 1+2+4 = 7) เพื่อใช้เป็นตัวหารเฉลี่ยปริมาณวัสดุแต่ละชนิด

**ส่วนการแปลงหน่วยและการแสดงผล (Material Conversion & UI)**
* **Cement Bags:** คำนวณจากส่วนแบ่งปูน หารด้วย 0.035 (ปริมาตรเฉลี่ยของปูน 50kg หนึ่งถุง) และใช้ `math.ceil` เพื่อปัดเศษขึ้นเสมอเพื่อให้วัสดุเพียงพอต่อการใช้งานจริง
* **Water Estimation:** อ้างอิงจากค่า W/C Ratio ประมาณ 0.5 (น้ำประมาณ 25 ลิตรต่อปูน 1 ถุง)
* **Data Visualization:** ใช้ไลบรารี **Matplotlib** เพื่อสร้างกราฟวงกลมแสดงสัดส่วนวัสดุ และใช้ `st.columns` เพื่อจัดวางผลลัพธ์ให้เป็นระเบียบ สวยงาม และอ่านง่ายเหมือน Dashboard มืออาชีพ

### **Verification (การตรวจสอบ)**
* **กรณีทดสอบ:** พื้นที่ 1.0 x 1.0 x 0.1 เมตร (0.1 $m^3$), Waste 0%, สัดส่วน 1:2:4
* **คำนวณมือ:** ปริมาตรแห้ง = $0.1 \times 1.54 = 0.154$ $m^3$ | ปริมาณปูน = $(1/7) \times 0.154 = 0.022$ $m^3$ | จำนวนถุง = $0.022 / 0.035 = 0.62$ ถุง $\rightarrow$ **ปัดขึ้นเป็น 1 ถุง**
* **ผลลัพธ์จากแอป:** แสดงค่าตรงกับการคำนวณมือ (ยืนยันความถูกต้องของแอปพลิเคชัน)
