### **User Manual: Concrete Mixture Calculator**
แอปพลิเคชันนี้ออกแบบมาเพื่อช่วยวิศวกรและผู้รับเหมาคำนวณปริมาณวัสดุผสมคอนกรีต (ปูน, ทราย, หิน, น้ำ) จากขนาดโครงสร้างที่ต้องการเทจริง

**ขั้นตอนการใช้งาน:**
1. **กรอกขนาดโครงสร้าง (Dimensions):** ผ่านแถบเมนูด้านซ้าย (Sidebar)
   * **Width:** ความกว้างของพื้นที่ (เมตร)
   * **Length:** ความยาวของพื้นที่ (เมตร)
   * **Thickness/Height:** ความหนาของพื้น หรือความสูงของเสา/คาน (เมตร)
2. **ระบุค่าเผื่อเหลือเผื่อขาด (% Waste):** ปรับเลื่อนแถบ **Slider** เพื่อกำหนดเปอร์เซ็นต์ที่ต้องการเผื่อ เช่น 5% หรือ 10% เพื่อป้องกันวัสดุไม่พอเนื่องจากการหกหล่นหรือพื้นผิวที่ไม่เรียบ
3. **เลือกสัดส่วนผสม (Mixing Ratio):** เลือกจากรายการ **Dropdown** ตามประเภทงาน:
   * **[1:1.5:3]:** สำหรับงานโครงสร้างที่ต้องการความแข็งแรงสูง (คาน, เสา)
   * **[1:2:4]:** สำหรับงานทั่วไป (พื้นบ้าน, ถนน)
   * **[1:3:5]:** สำหรับงานโครงสร้างไม่รับแรงมาก (ลีนคอนกรีต, ปรับระดับพื้น)
4. **การอ่านผลลัพธ์:** แอปจะแสดงผลลัพธ์แบบ Real-time บนหน้าจอหลัก ทั้งในรูปแบบตัวเลขสรุป (Metrics) และกราฟวงกลม (Pie Chart) แสดงจำนวนถุงปูน (ปัดเศษขึ้น), ปริมาตรทรายและหิน (ลบ.ม.), และปริมาณน้ำโดยประมาณ

### **Explanation of Code (ฉบับสมบูรณ์)**
โค้ดชุดนี้ถูกออกแบบโดยเน้นความถูกต้องตามหลักวิศวกรรมโยธา (ACI Standard) และการใช้งานที่ง่ายผ่านระบบ Cloud โดยแบ่งโครงสร้างโค้ดออกเป็นส่วนๆ ดังนี้:

**1. ส่วนรับข้อมูลและป้องกันข้อผิดพลาด (Input & Validation)**
* ใช้ฟังก์ชัน `st.sidebar.number_input` และ `st.sidebar.slider` เพื่อรับค่าจากผู้ใช้ 
* **จุดเด่น:** ระบบจะทำการตรวจสอบชนิดข้อมูลอัตโนมัติ (Validation) ทำให้ผู้ใช้ไม่สามารถกรอกตัวอักษรหรือค่าที่ติดลบได้ ช่วยป้องกันโปรแกรมค้าง (Crash) และลดความผิดพลาดจาก Human Error

**2. ตรรกะการคำนวณทางวิศวกรรม (Engineering Logic)**
* **Net Volume:** คำนวณปริมาตรสุทธิตามรูปทรงเลขาคณิต ($V = W \times L \times H$)
* **Shrinkage Factor (1.54):** นี่คือหัวใจสำคัญของโค้ด โดยมีการคูณปริมาตรสุทธิด้วยค่า **1.54** เพื่อหาปริมาตรวัสดุแห้ง (Dry Volume) เนื่องจากวัสดุผสมเมื่อเติมน้ำและทำการบดอัด ปริมาตรจะลดลงจากเดิมประมาณ 30-35% การคำนวณเผื่อค่านี้จึงช่วยให้สั่งวัสดุมาหน้างานได้อย่างถูกต้อง ไม่ขาดแคลนระหว่างเทคอนกรีต
* **Sum Ratio:** ใช้วิธีหาผลรวมสัดส่วนเพื่อกระจายสัดส่วนวัสดุ (เช่น 1:2:4 รวมเท่ากับ 7 ส่วน) ทำให้การคำนวณมีความยืดหยุ่นตามสัดส่วนผสมที่เลือก

**3. การแปลงหน่วยและการแสดงผล (Material Conversion & UI)**
* **Cement Bags:** แปลงปริมาตรปูนเป็นจำนวนถุง โดยหารด้วย 0.035 $m^3$ (ปริมาตรเฉลี่ยของปูน 1 ถุง) และใช้ `math.ceil` เพื่อปัดเศษขึ้นเสมอ เพราะในทางปฏิบัติปูนขาดจะทำให้งานหยุดชะงัก แต่ปูนเหลือสามารถเก็บไว้ใช้ต่อได้
* **Data Visualization:** ใช้ไลบรารี **Matplotlib** สร้างกราฟวงกลม (Pie Chart) เพื่อแสดงสัดส่วนวัสดุเปรียบเทียบ ช่วยให้วิศวกรหน้างานตรวจสอบความถูกต้องของส่วนผสมได้ด้วยตาเปล่าทันที
* **Layout:** ใช้ `st.columns` และ `st.metric` จัดวางข้อมูลแบบ Dashboard เพื่อความสวยงามและอ่านง่าย

**4. การจัดการระบบ (Cloud Deployment)**
* มีการใช้ไฟล์ **`requirements.txt`** เพื่อระบุ Library ที่จำเป็น (Streamlit, Matplotlib, Pandas) ทำให้แอปพลิเคชันสามารถติดตั้งสภาพแวดล้อมและรันบนระบบ Cloud (Streamlit Cloud) ได้โดยอัตโนมัติจาก GitHub ทำให้ผู้ร่วมงานทุกคนเข้าถึงแอปได้ผ่าน URL ตลอดเวลา

### **Verification (การตรวจสอบความถูกต้อง)**
* **กรณีทดสอบ:** พื้นที่ 1.0 x 1.0 x 0.1 เมตร (ปริมาตรเปียก 0.1 $m^3$), สัดส่วน 1:2:4
* **คำนวณมือ:** ปริมาตรแห้ง = $0.1 \times 1.54 = 0.154$ $m^3$ 
* **ปริมาณปูนที่ใช้:** $(1/7) \times 0.154 = 0.022$ $m^3$ 
* **จำนวนถุง:** $0.022 / 0.035 = 0.62$ ถุง $\rightarrow$ **ปัดขึ้นเป็น 1 ถุง**
* **ผลลัพธ์จากแอป:** แสดงค่า "1 Bag" ตรงตามการคำนวณมือ ยืนยันว่าโค้ดทำงานถูกต้องแม่นยำ
