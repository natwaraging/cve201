# 🏗️ Concrete Mixture Calculator Pro (ACI Standard)

### **1. User Manual: คู่มือการใช้งานแอปพลิเคชัน**
แอปพลิเคชันนี้ออกแบบมาเพื่อช่วยวิศวกรและผู้รับเหมาคำนวณปริมาณวัสดุผสมคอนกรีต (ปูน, ทราย, หิน, น้ำ) จากขนาดโครงสร้างที่ต้องการเทจริง โดยมีการคำนวณที่แม่นยำตามหลักวิศวกรรม

**ขั้นตอนการใช้งาน:**
1.  **กรอกขนาดโครงสร้าง (Dimensions):** ระบุค่าผ่านแถบเมนูด้านซ้าย (Sidebar)
    * **Width:** ความกว้างของพื้นที่ (เมตร)
    * **Length:** ความยาวของพื้นที่ (เมตร)
    * **Thickness/Height:** ความหนาของพื้น หรือความสูงของเสา/คาน (เมตร)
2.  **ระบุค่าเผื่อเหลือเผื่อขาด (% Waste):** ปรับเลื่อนแถบ **Slider** เพื่อกำหนดเปอร์เซ็นต์วัสดุเผื่อเหลือ (แนะนำ 5-10%) เพื่อป้องกันวัสดุไม่พอเนื่องจากการหกหล่นหรือพื้นผิวที่ไม่เรียบ
3.  **เลือกสัดส่วนผสม (Mixing Ratio):** เลือกจากรายการ **Dropdown** ตามประเภทงานก่อสร้าง:
    * **[1:1.5:3]:** สำหรับงานโครงสร้างแข็งแรงสูง (คาน, เสา)
    * **[1:2:4]:** สำหรับงานทั่วไป (พื้นบ้าน, ถนน)
    * **[1:3:5]:** สำหรับงานโครงสร้างไม่รับแรงมาก (ลีนคอนกรีต, ปรับระดับพื้น)
4.  **การอ่านผลลัพธ์:** แอปจะแสดงผลลัพธ์แบบ Real-time บนหน้าจอหลัก ประกอบด้วยปริมาตรรวม, จำนวนถุงปูน (ปัดเศษขึ้น), ปริมาตรทรายและหิน (ลบ.ม.) พร้อมกราฟวงกลม (Pie Chart) แสดงสัดส่วนวัสดุอย่างชัดเจน

### **2. Explanation of Code: เจาะลึกตรรกะและการทำงานของโปรแกรม**
เพื่อให้เห็นภาพการทำงานของระบบ โค้ดถูกแบ่งออกเป็น 4 ส่วนหลักตามโครงสร้างวิศวกรรมซอฟต์แวร์:

#### **A. ส่วนรับข้อมูล (The Interface)**
* **Sidebar Control:** ใช้ `st.sidebar` เพื่อแยกส่วนควบคุมข้อมูลออกจากการแสดงผล ทำให้ Dashboard ดูเป็นระเบียบ
* **Data Validation:** ใช้ `number_input` บังคับให้รับเฉพาะตัวเลข และกำหนด `min_value` เพื่อป้องกันความผิดพลาดกรณีผู้ใช้ใส่ค่าติดลบ หรือค่าที่เป็นตัวอักษร ซึ่งจะช่วยป้องกันโปรแกรมค้าง (Crash)

#### **B. ส่วนตรรกะการคำนวณ (Engineering Logic)**
* **Wet Volume:** คำนวณปริมาตรจากรูปทรงเรขาคณิตพื้นฐาน ($V = W \times L \times H$)
* **The 1.54 Factor (Shrinkage):** ในทางวิศวกรรม คอนกรีตตอนเป็น "ส่วนผสมแห้ง" จะมีช่องว่างอากาศสูง แต่เมื่อผสมน้ำและบดอัดจะมีการยุบตัวลง 30-35% โปรแกรมจึงใช้ตัวคูณ **1.54** เพื่อพยากรณ์ปริมาณวัสดุแห้งที่ต้องใช้จริงก่อนผสมน้ำ
* **Ratio Distribution:** ใช้วิธีนำผลรวมของสัดส่วนผสม (Sum Ratio) มาเป็นตัวหาร เพื่อกระจายปริมาณวัสดุตามอัตราส่วนที่เลือก (เช่น สัดส่วน 1:2:4 รวมคือ 7 ส่วน ปูนจะคิดเป็น 1/7 ของปริมาตรแห้งทั้งหมด)

#### **C. การแปลงหน่วยวัสดุหน้างาน (Material Conversion)**
* **Cement Packaging:** คำนวณปริมาตรปูนหารด้วย **0.035** (ปริมาตรเฉลี่ยของปูน 50 กก. จำนวน 1 ถุง) และใช้คำสั่ง `math.ceil` เพื่อ **ปัดเศษขึ้นเสมอ** เพราะในงานก่อสร้างการมีปูนเหลือดีกว่าปูนขาด
* **Water Estimation:** อ้างอิงจากค่า Water-Cement Ratio โดยประมาณคือ 25 ลิตร ต่อปูน 1 ถุง เพื่อความสะดวกในการเตรียมน้ำหน้างาน

#### **D. ส่วนการแสดงผลและ Visual Display**
* **Real-time Metrics:** ใช้ `st.metric` เพื่อโชว์ตัวเลขสำคัญเหมือนหน้าปัด Dashboard ทำให้อ่านง่าย
* **Data Visualization:** ใช้ `Matplotlib` แปลงตัวเลขที่ซับซ้อนให้เป็น **Pie Chart** เพื่อให้วิศวกรสามารถตรวจสอบสัดส่วนวัสดุด้วยตาเปล่าได้ทันที (เช่น หินต้องมีสัดส่วนมากที่สุดเสมอ)

### **3. Verification: การตรวจสอบความถูกต้อง**
* **กรณีทดสอบ:** พื้นที่ 1.0 x 1.0 x 0.1 เมตร (ปริมาตรเปียก 0.1 ลบ.ม.), สัดส่วน 1:2:4, เผื่อวัสดุ 0%
* **คำนวณมือ:**
    * ปริมาตรแห้ง = $0.1 \times 1.54 = 0.154$ ลบ.ม.
    * ปริมาณปูนที่ใช้ = $(1/7) \times 0.154 = 0.022$ ลบ.ม.
    * จำนวนถุงปูน = $0.022 / 0.035 = 0.62$ ถุง $\rightarrow$ **ปัดขึ้นเป็น 1 ถุง**
* **ผลลัพธ์จากแอปพลิเคชัน:** แสดงค่าตรงกับการคำนวณมือ ยืนยันความถูกต้องของอัลกอริทึม
