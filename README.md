# cve201
User Manual: 
Concrete Mixture Calculator แอปพลิเคชันนี้ออกแบบมาเพื่อช่วยวิศวกรและผู้รับเหมาคำนวณปริมาณวัสดุผสมคอนกรีต (ปูน, ทราย, หิน, น้ำ) จากขนาดโครงสร้างที่ต้องการเทจริง
ขั้นตอนการใช้งาน:
  กรอกขนาดโครงสร้าง(Dimensions) : Width ความกว้างของพื้นที่ (เมตร), Length ความยาวของพื้นที่ (เมตร), Thickness/Height ความหนาของพื้น หรือความสูงของเสา/คาน (เมตร)
  ระบุค่าเผื่อเหลือเผื่อขาด(% Waste)  :กรอกตัวเลขเปอร์เซ็นต์ที่ต้องการเผื่อ เช่น 5 หรือ 10 เพื่อป้องกันวัสดุไม่พอเนื่องจากการหกหล่นหรือพื้นผิวที่ไม่เรียบ
  เลือกสัดส่วนผสม(Mixing Ratio) : กด1 [1:1.5:3] สำหรับงานโครงสร้างที่ต้องการความแข็งแรงสูง (คาน, เสา), กด2 [1:2:4] สำหรับงานทั่วไป (พื้นบ้าน, ถนน), กด3 [1:3:5]: สำหรับงานโครงสร้างไม่รับแรงมาก (ลีนคอนกรีต, ปรับระดับพื้น)
การอ่านผลลัพธ์:
  แอปจะแสดงจำนวนถุงปูน (ปัดเศษขึ้นให้แล้ว), ปริมาตรทรายและหินเป็นคิว (ลบ.ม.), และปริมาณน้ำโดยประมาณ

Explanation of Code 
โค้ดชุดนี้แบ่งการทำงานออกเป็นส่วนๆ อย่างเป็นระบบ ดังนี้
1. ส่วนป้องกันข้อผิดพลาด
   def get_float_input(prompt):
    while True:
        try:
            return float(input(prompt))
        except ValueError:
            print("❌ Please enter a valid number.")
    ทำหน้าที่ตรวจสอบว่าผู้ใช้พิมพ์ตัวเลขจริงหรือไม่ หากพิมพ์ตัวอักษร โปรแกรมจะไม่ค้าง แต่จะแจ้งเตือนและให้พิมพ์ใหม่จนกว่าจะถูกต้อง
2. ส่วนตรรกะการคำนวณ
   Net Volume: คำนวณปริมาตรจริงจากรูปทรงสี่เหลี่ยม
   Total Volume: นำปริมาตรจริงมาคูณกับค่า Waste เช่น ถ้าเผื่อ 10% จะเท่ากับคูณด้วย 1.10
                 การคูณด้วย 1.54: นี่คือจุดสำคัญ เพราะคอนกรีตเมื่อผสมน้ำจะมีการยุบตัวและช่องว่างอากาศหายไป เราจึงต้องคูณด้วย 1.54 เพื่อหาปริมาตรวัสดุแห้งก่อนผสม
   Sum Ratio: นำสัดส่วนที่เลือกมาบวกกัน (เช่น 1+2+4 = 7) เพื่อใช้เป็นตัวหารเฉลี่ยปริมาณวัสดุแต่ละชนิด
3. ส่วนการแปลงหน่วยวัสดุ
   Cement Bags: (ส่วนแบ่งปูน / ผลรวมสัดส่วน) * ปริมาตรแห้งการแปลง: หารด้วย 0.035 (ปริมาตรเฉลี่ยของปูน 50kg หนึ่งถุง) และใช้ math.ceil เพื่อปัดเศษขึ้นเสมอ (เพราะปูนขาดเทต่อไม่ได้ แต่ปูนเหลือยังเก็บไว้ได้)
   Water Estimation: อ้างอิงจากค่า W/C Ratio (Water-Cement Ratio) ประมาณ 0.5 ซึ่งโดยทั่วไปปูน 1 ถุง จะใช้น้ำประมาณ 25 ลิตร
4. ส่วนการแสดงผล 
  print(f"✅ Cement (50kg bags): {cement_bags:>8}") มีการใช้ F-string formatting (:>8.2f) เพื่อจัดวางตัวเลขให้ชิดขวาและมีทศนิยม 2 ตำแหน่ง ทำให้รายงานผลลัพธ์ดูเป็นระเบียบ อ่านง่ายเหมือนใบเสร็จ
